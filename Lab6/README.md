## 📌 Опис роботи

Робота присвячена розв'язанню систем лінійних алгебраїчних рівнянь (СЛАР) $AX = B$ розмірності $n \times n$ ($n = 100$) за допомогою $LU$-розкладу за схемою Дуліттла та наступному ітераційному уточненню отриманого розв'язку до досягнення граничної точності $eps_0 = 10^{-14}$.

### Теоретична основа:
1. **$LU$-розклад Дуліттла:**
   $$A = L \cdot U$$
   де $L$ — нижня трикутна матриця ($l_{ij} = 0$ при $j > i$), $U$ — верхня трикутна матриця з одиничною діагоналлю ($u_{ii} = 1$, $u_{ji} = 0$ при $j > i$).
   - Для стовпця $k$ матриці $L$ ($i \ge k$):  
     $$l_{ik} = a_{ik} - \sum_{j=1}^{k-1} l_{ij} u_{jk}$$
   - Для рядка $k$ матриці $U$ ($i > k$):  
     $$u_{ki} = \frac{1}{l_{kk}} \left( a_{ki} - \sum_{j=1}^{k-1} l_{kj} u_{ji} \right)$$

2. **Розв'язання системи $AX = B$:**
   - Прямий хід ($L \cdot Z = B$):
     $$z_1 = \frac{b_1}{l_{11}}, \quad z_k = \frac{1}{l_{kk}} \left( b_k - \sum_{j=1}^{k-1} l_{kj} z_j \right), \quad k = 2, \ldots, n$$
   - Зворотний хід ($U \cdot X = Z$):
     $$x_n = z_n, \quad x_k = z_k - \sum_{j=k+1}^n u_{kj} x_j, \quad k = n-1, \ldots, 1$$

3. **Ітераційне уточнення розв'язку:**
   - Вектор нев'язки: $R = B - A X^{(k)}$
   - Вектор поправки: $A \cdot \Delta X = R$ (розв'язується через готовий $LU$-розклад: $L Z = R$, $U \Delta X = Z$, складність $O(n^2)$)
   - Уточнення: $X^{(k+1)} = X^{(k)} + \Delta X$
   - Критерій закінчення: $\|\Delta X\|_\infty \le eps_0$ та $\|AX - B\|_\infty \le eps_0$ ($eps_0 = 10^{-14}$).

## 📊 Результати обчислювального експерименту

- **Розмірність задачі:** $n = 100$
- **Контрольний точний розв'язок:** $x_i = 2.5 \quad (i = 1, \dots, 100)$
- **Точність факторизації:** $\|A - L \cdot U\|_\infty = 1.352 \times 10^{-12}$
- **Первинний розв'язок ($LU$-розклад):**
  - Початкова нев'язка: $\|A X^{(0)} - B\|_\infty = 2.350 \times 10^{-11}$
  - Похибка відносно точного вектора: $\|X^{(0)} - X^*\|_\infty = 1.268 \times 10^{-12}$

### Збіжність ітераційного уточнення:

| Ітерація ($k$) | Норма поправки $\|\Delta X\|$ | Норма нев'язки $\|AX - B\|$ | Похибка $\|X - X^*\|$ |
| :---: | :---: | :---: | :---: |
| **1** | $1.266 \times 10^{-12}$ | $2.350 \times 10^{-11}$ | $7.994 \times 10^{-15}$ |
| **2** | $2.181 \times 10^{-16}$ | $1.581 \times 10^{-14}$ | $7.994 \times 10^{-15}$ |

**Підсумок:**  
Критерій закінчення ітерацій $\|\Delta X\|_\infty \le 10^{-14}$ досягнуто за **2 ітерації**. Абсолютна похибка відносно точного розв'язку зменшилася з $1.268 \times 10^{-12}$ до $7.994 \times 10^{-15}$, досягнувши межі розрядної сітки 64-бітних дійсних чисел IEEE-754.
