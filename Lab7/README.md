## Опис роботи

Програмна реалізація та дослідження збіжності трьох класичних ітераційних методів розв’язку систем лінійних алгебраїчних рівнянь (СЛАР) $AX = B$ розмірності $100 \times 100$:
1. **Метод простої ітерації** ($X^{(k+1)} = (E - \tau A) X^{(k)} + \tau B$ при $\tau = 1 / \|A\|_\infty$);
2. **Метод Якобі** (одночасних зміщень);
3. **Метод Гауса-Зейделя** (послідовних зміщень).

Матриця $A$ згенерована зі строгим діагональним переважанням ($|a_{ii}| > \sum_{j \neq i} |a_{ij}|$).  
Контрольний розв'язок: $x_i^* = 2.5$ ($i = 1, \dots, 100$).  
Початкове наближення: $x_i^{(0)} = 1.0$ ($i = 1, \dots, 100$).  
Цільова точність зупинки: $\|X^{(k+1)} - X^{(k)}\|_\infty < 10^{-14}$.
