# Лабораторна робота №8: Чисельні методи розв’язування нелінійних та алгебраїчних рівнянь

Програмна реалізація, дослідження збіжності та порівняльний аналіз однокрокових і багатокрокових ітераційних методів розв’язування одновимірних трансцендентних та алгебраїчних рівнянь із точністю $\varepsilon = 10^{-10}$.

---

## 📌 Постановка задачі

### 1. Трансцендентне рівняння:
$$F(x) = e^{-x} - \sin(x) = 0, \quad x \in [0.0, 4.0], \quad h = 0.1$$

- **Табуляція та ізоляція коренів:** знайдено два проміжки зміни знака функції з протилежною поведінкою:
  - **Корінь 1:** $x_1^* \in [0.5, 0.6]$, похідна $F'(x) < 0$ (функція монотонно спадає);
  - **Корінь 2:** $x_2^* \in [3.0, 3.1]$, похідна $F'(x) > 0$ (функція монотонно зростає).
- **Досліджувані методи уточнення (6 методів):**
  1. Метод простої ітерації (релаксації): $x_{n+1} = x_n + \tau F(x_n)$ ($\tau > 0$ при $F' < 0$, $\tau < 0$ при $F' > 0$);
  2. Метод Ньютона (дотичних): $x_{n+1} = x_n - \frac{F(x_n)}{F'(x_n)}$ ($p = 2$);
  3. Метод Чебишева (третього порядку): $x_{n+1} = x_n - \frac{F(x_n)}{F'(x_n)} - \frac{1}{2}\frac{F^2(x_n) F''(x_n)}{(F'(x_n))^3}$ ($p = 3$);
  4. Метод хорд (січних): $x_{n+1} = x_n - F(x_n)\frac{x_n - x_{n-1}}{F(x_n) - F(x_{n-1})}$ ($p \approx 1.618$);
  5. Метод парабол (Мюллера): квадратична інтерполяція за 3 вузлами ($p \approx 1.84$);
  6. Метод зворотної інтерполяції: обчислення інтерполяційного полінома Лагранжа $x = L(y)$ при $y = 0$ за 3 вузлами.
- **Критерій завершення ітерацій:** одночасне виконання двох умов:
  $$|F(x_{n+1})| < 10^{-10} \quad \text{та} \quad |x_{n+1} - x_n| < 10^{-10}$$

### 2. Алгебраїчне рівняння 3-го порядку:
$$P(x) = (x - 2)((x - 1)^2 + 2^2) = x^3 - 4x^2 + 9x - 10 = 0$$

- **Коефіцієнти:** $a_3 = 1.0, \, a_2 = -4.0, \, a_1 = 9.0, \, a_0 = -10.0$ (збережені у `polynomial.txt`).
- **Контрольні аналітичні розв'язки:**
  - Дійсний корінь: $x_1 = 2.0$;
  - Комплексно-спряжені корені: $x_{2,3} = 1.0 \pm 2.0i$.
- **Методи розв'язання:**
  - Метод Ньютона зі схемою Горнера для обчислення $P(x_n) = b_0$ та $P'(x_n) = c_1$;
  - Метод Ліна для знаходження комплексно-спряжених коренів $\alpha \pm i\beta$.

### 2. Алгебраїчне рівняння $P(x) = x^3 - 4x^2 + 9x - 10 = 0$

- **Дійсний корінь (Ньютон + схема Горнера):**  
  $x = 2.0000000000$, знайдено за **6 ітерацій**, нев'язка $|P(x)| = 1.28 \times 10^{-13}$, приріст $|\Delta x| = 2.58 \times 10^{-14}$.
- **Комплексно-спряжені корені (метод Ліна):**  
  $\alpha = 1.0000000000$, $\beta = 2.0000000000$ ($x_{2,3} = 1.0 \pm 2.0i$), знайдено за **18 ітерацій**, максимальна похибка $6.49 \times 10^{-11} < 10^{-10}$.

## 📌 Висновок
Експериментально підтверджено теоретичні властивості збіжності: найшвидшими виявилися метод Чебишева 3-го порядку та метод парабол (по 3 ітерації). Багатокрокові методи (хорд, парабол, зворотної інтерполяції) досягають високої надлінійної швидкості без потреби обчислення аналітичних похідних. Схема Горнера мінімізує кількість арифметичних операцій, а метод Ліна надійно знаходить комплексно-спряжені корені многочлена без використання комплексних чисел у процесі ділення.
