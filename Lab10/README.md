# Лабораторна робота №10: Чисельні методи розв’язування задачі Коші для звичайних диференціальних рівнянь

Програмна реалізація, дослідження точності та порівняльний аналіз класичного явного однокрокового методу Рунге-Кутта 4-го порядку та двоетапного багатокрокового методу прогнозу й корекції Адамса 2-го порядку з автоматичним вибором кроку інтегрування.

---

## 📌 Постановка задачі

### 1. Задача Коші для диференціального рівняння першого порядку:
$$\frac{dy}{dx} = f(x, y) = y - x^2 + 1, \quad x \in [0.0, 2.0], \quad y(0.0) = 0.5$$

- **Точний аналітичний розв'язок (метод інтегруючого множника $\mu(x) = e^{-x}$):**
  $$y(x) = (x + 1)^2 - 0.5 e^x$$
- **Контрольні значення:**  
  $y(0.0) = 0.5000000000$,  
  $y(1.0) = 4 - 0.5e \approx 2.6408590858$,  
  $y(2.0) = 9 - 0.5e^2 \approx 5.3054719505$.

### 2. Досліджувані методи чисельного інтегрування:
1. **Метод Рунге-Кутта 4-го порядку (Ч.2):**
   - Розрахункова схема з коефіцієнтами $k_1, k_2, k_3, k_4$ на сітці $h = 10^{-2} = 0.01$;
   - Дослідження порядку апроксимації $O(h^4)$ на сітці кроків $h \in \{0.1, 0.05, 0.02, 0.01, 0.005\}$;
   - Апостеріорна оцінка похибки за правилом Рунге:
     $$\Phi_n = \frac{16}{15} |y_n^{h/2} - y_n^h|$$
   - Автоматичний вибір кроку за правилом подрібнення/подвоєння ($k = 2^5 = 32$) для гарантування $\varepsilon = 10^{-6}$.
2. **Метод прогнозу та корекції Адамса 2-го порядку (Ч.1):**
   - Розгінний вузол $(x_1, y_1)$ обчислюється методом RK4;
   - Прогноз за формулою Адамса-Башфорта 2-го порядку: $y_{n+1}^{пр} = y_n + \frac{h}{2}(3f_n - f_{n-1})$;
   - Модифікація прогнозу за залишковим членом: $y_{n+1}^{мод} = y_{n+1}^{пр} + \frac{5}{6}(y_n^{кор} - y_n^{пр})$;
   - Ітераційна корекція за формулою Адамса-Моултона 2-го порядку (трапецій): $y_{n+1}^{(i+1)} = y_n + \frac{h}{2}[f(x_{n+1}, y_{n+1}^{(i)}) + f_n]$;
   - Оцінка залишкової похибки $R_2^{кор} = -\frac{1}{6}(y_{n+1}^{кор} - y_{n+1}^{пр})$ та кінцеве коригування;
   - Автоматичний вибір кроку ($k = 2^3 = 8$) для гарантування $\varepsilon = 10^{-4}$.

## 📌 Висновок

1. Метод Рунге-Кутта 4-го порядку має найвищу точність серед однокрокових методів ($p = 4.00$, похибка порядку $10^{-10}$ при $h = 0.01$), а правило Рунге дає винятково точну оцінку похибки без знання аналітичного розв'язку.
2. Двоетапний метод прогнозу й корекції Адамса 2-го порядку є обчислювально економнішим за рахунок багатокрокової схеми, потребуючи лише 1–2 виклики правої частини на крок при швидкій збіжності ітерацій коректора (5 ітерацій за умови $\frac{h}{2}|\frac{\partial f}{\partial y}| = 0.025 \ll 1$).
3. Алгоритми автоматичного регулювання кроку $h(x)$ суттєво скорочують кількість обчислювальних вузлів (у 5–9 разів), гарантуючи надійне виконання заданих критеріїв точності.
