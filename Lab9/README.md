# Лабораторна робота №9: Метод Хука-Дживса багатовимірної оптимізації

Програмна реалізація методу нульового порядку Хука-Дживса (Hooke-Jeeves Pattern Search) для багатовимірної безумовної оптимізації та чисельного розв’язування систем нелінійних рівнянь.

---

## 📌 Постановка задачі

### 1. Тестова цільова функція Розенброка:
$$f(x_1, x_2) = 100(x_1^2 - x_2)^2 + (x_1 - 1)^2, \quad X^{(0)} = (-1.2; 0.0)^T$$

- **Теоретичний оптимум:** $X^* = (1.0; 1.0)^T$, $f(X^*) = 0$.
- **Мета тесту:** перевірка роботи евристичного прискорення за зразком уздовж вузького криволінійного яру ("Banana valley").

### 2. Система нелінійних рівнянь ($m = 2$):
$$\begin{cases}
f_1(x_1, x_2) = x_1^2 + x_2^2 - 4 = 0 \quad (\text{коло } R = 2) \\
f_2(x_1, x_2) = x_2 - \sin(x_1) - 1 = 0 \quad (\text{синусоїда, зміщена на 1})
\end{cases}$$

- **Допоміжна цільова функція:**
  $$\Phi(x_1, x_2) = f_1^2(x_1, x_2) + f_2^2(x_1, x_2) = (x_1^2 + x_2^2 - 4)^2 + (x_2 - \sin(x_1) - 1)^2 \to \min$$
  У точці точного розв'язку $\Phi(X^*) = 0$.
- **Графічна локалізація та початкові наближення:**
  - **Корінь 1 (I квадрант):** $X_1^{(0)} = (1.0; 1.5)^T$, крок $\Delta X = (0.2; 0.2)^T$;
  - **Корінь 2 (II квадрант):** $X_2^{(0)} = (-1.8; 0.2)^T$, крок $\Delta X = (0.2; 0.2)^T$.
- **Критерії завершення пошуку:**
  $$\|\Delta X\| < \varepsilon_1 = 10^{-7} \quad \text{та} \quad |\Phi(X^{(k+1)}) - \Phi(X^{(k)})| < \varepsilon_2 = 10^{-10}$$

## 📌 Висновок

Метод нульового порядку Хука-Дживса успішно розв'язує задачу знаходження коренів системи нелінійних рівнянь через мінімізацію суми квадратів нев'язок без потреби обчислення похідних або обернення матриці Якобі. Дослідження підтвердили високу ефективність екстраполяції за зразком, стійкість до яружного рельєфу та можливість швидкого досягнення високої точності ($\Phi < 10^{-13}$, нев'язки $\sim 10^{-8} \dots 10^{-7}$).
